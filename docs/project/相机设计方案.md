# 相机配置方案
项目计划使用多个相机，每个相机提供符合要求的接口即可在 online record launch 文件当中被使用从而记录多个视角的 image 图像数据。应该将每一种相机封装为一个类或是节点或是函数，向上提供持续的 image 数据流，online 端在不记录数据时就只将该 image 送入到预览当中，而不需要将其存储下来。当处于记录状态时则将多路 image 分别封装为相应的 mp4 文件。
相机类应该保存或者读取已有 config 文件当中保存的对应相机的接口，也就是 /dev/video*，该记录只作为一个默认值，未被特殊指定时默认使用。当然也可以在 online record launch 文件调用时指定，有指定时使用指定的。
