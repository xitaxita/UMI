## Project context and closeout

- Before starting or resuming coding, read `coding_context.md` and the active task, then inspect the relevant code and working-tree changes.
- Read requirements and architecture documents as needed; their current locations are listed in `coding_context.md`.
- Keep `project.md` as the user-facing progress board.
- Record explicit development decisions in the appropriate project record before implementing affected work.
- After code changes or meaningful status changes, verify and synchronize both `coding_context.md` and `project.md`.
- Preserve existing user changes and distinguish implementation, verification, and hardware acceptance.
